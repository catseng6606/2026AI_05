第一關：基礎選取

SELECT * FROM table1;

Excel 邏輯做法：

當你在 Excel 打開工作簿，點選下方的 Sheet1 (員工表)，並用滑鼠圈選或查看整張表格時，你其實就是在進行資料的「全選」。

操作：點擊 Sheet1 標籤 ➔ Ctrl + A

SQL 語法結構：

SQL 中，我們使用 SELECT 來指定要拿取哪些欄位（* 代表全部），並用 FROM 指向我們的資料表（工作表）。

SELECT * FROM table1;
關鍵金句： 「SQL 的 FROM 代表 Excel 的分頁名稱，SELECT 代表你框選的欄位範圍。」
