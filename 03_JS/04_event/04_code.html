Prism.js 程式碼高亮示範

本頁面示範如何使用 Prism.js 在網頁上呈現高亮後的 Python 與 HTML 程式碼區塊，並修正了將 <pre> 標籤寫在 <head> 中的結構問題。

1. Python Hello World 程式碼區塊
# 這是一段 Python 的 Hello World 程式碼
def say_hello(name="World"):
    print(f"Hello, {name}!")

say_hello("Python")
實體元件 HTML 原始碼：
<pre><code class="language-python"># 這是一段 Python 的 Hello World 程式碼
def say_hello(name="World"):
    print(f"Hello, {name}!")

say_hello("Python")</code></pre>
2. HTML 程式碼區塊
<div class="hello">Hello World</div>
實體元件 HTML 原始碼：
<pre><code class="language-html">&lt;div class="hello"&gt;Hello World&lt;/div&gt;</code></pre>
