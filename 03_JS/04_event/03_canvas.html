JS addEventListener 效果對比 (Canvas 繪圖)

本範例展示了兩個 Canvas 畫布的對比。畫布 A 使用了 addEventListener 監聽滑鼠事件，實現了塗鴉功能與即時滑鼠座標顯示；而 畫布 B 則沒有監聽任何事件，滑鼠移入時無法取得座標，也無法進行任何繪圖互動。

畫布 A (已綁定 addEventListener)
滑鼠座標：X: -, Y: -
實體元件 HTML 結構：
<canvas id="canvasA" width="400" height="300"></canvas>
<div id="coordsA">滑鼠座標：X: -, Y: -</div>
JavaScript 事件監聽代碼：
const canvasA = document.getElementById('canvasA');
const ctxA = canvasA.getContext('2d');
const coordsA = document.getElementById('coordsA');
let isDrawingA = false;

// 1. 監聽 mousedown (按下) -> 開始繪圖並畫點
canvasA.addEventListener('mousedown', (e) => {
  isDrawingA = true;
  ctxA.beginPath();
  ctxA.moveTo(e.offsetX, e.offsetY);
  ctxA.lineTo(e.offsetX, e.offsetY); // 點擊時即時畫出一個點 (修正單點無反應 bug)
  ctxA.stroke();
});

// 2. 監聽 mousemove (移動) -> 繪製線條並即時顯示滑鼠 X, Y 座標
canvasA.addEventListener('mousemove', (e) => {
  // 更新網頁上的滑鼠 X, Y 座標值
  coordsA.textContent = `X: ${e.offsetX}, Y: ${e.offsetY}`;
  
  if (isDrawingA) {
    ctxA.lineTo(e.offsetX, e.offsetY);
    ctxA.stroke();
  }
});

// 3. 監聽 mouseup (放開) 與 mouseleave (移出) -> 停止繪圖
canvasA.addEventListener('mouseup', () => isDrawingA = false);
canvasA.addEventListener('mouseleave', () => {
  isDrawingA = false;
  coordsA.textContent = 'X: -, Y: -'; // 重置座標顯示
});
畫布 B (未綁定 addEventListener)
滑鼠座標：偵測不到 (無監聽器)
實體元件 HTML 結構：
<canvas id="canvasB" width="400" height="300"></canvas>
<div id="coordsB">滑鼠座標：偵測不到 (無監聽器)</div>
JavaScript 事件監聽代碼：
// 畫布 B 沒有綁定任何 addEventListener
// 因此無法更新滑鼠座標，也無法進行繪圖
