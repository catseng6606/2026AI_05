JavaScript let 與 const 變數宣告教學

請開啟瀏覽器開發者工具 (F12) 查看 Console 輸出結果。

原始碼參考：

<script>
  // let 宣告的變數可以重新賦值
  let i = 10;
  console.log(i); // 10
  i = 20;
  console.log(i); // 20
</script>
<script>
  // const 宣告的是常數，不可重新賦值
  const j = 30;
  console.log(j); // 30
  // j = 40; // 若將此行註解取消，會導致報錯：Uncaught TypeError: Assignment to constant variable.
</script>
