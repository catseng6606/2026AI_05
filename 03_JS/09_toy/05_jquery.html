概念一

jQuery 到底在「選」什麼？

jQuery 最強大的地方在於 $() 函數。它會掃描整個 HTML DOM 樹，並把符合條件的元素「打包成一個陣列群組」，讓你可以一次控制全部！

概念二

神奇的鏈式寫法 (Chaining)

在 jQuery 中，大部分的方法都會回傳 jQuery 物件本身。這意味著你可以像火車一樣，把好幾個指令連在一起寫，不需要重複選取元素！
