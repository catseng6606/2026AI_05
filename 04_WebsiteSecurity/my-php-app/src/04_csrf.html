SameSite Cookie 是如何阻止的？

當設定為 `SameSite=Strict` 時，瀏覽器會嚴格限制：只有在瀏覽器的網址列正是該銀行（SameSite）時，才會發送 Cookie。當從駭客的外部網站發出請求，Cookie 不會被帶上，因此後端會判定為「未登入」而拒絕轉帳。

CSRF Token 是如何阻止的？

CSRF Token 是一個隨機字串，駭客因為無法讀取 Alice 在銀行網頁上的內容（同源政策保護），因此在他的惡意 HTML 程式碼中，根本無法猜出並附帶正確的 Token 值，此時後端比對不符，轉帳請求便告失敗。
